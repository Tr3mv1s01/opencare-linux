# Участие в разработке

Проект находится в стадии Beta 0.0.1. Предложения и исправления приветствуются.

1. Для ошибки укажите шаги воспроизведения, версию Python, дистрибутив и рабочий стол.
2. Используйте временные каталоги для тестов изменяющих операций. Не запускайте очистку реальных данных в CI.
3. Перед pull request выполните `python3 -m unittest discover -s tests -v`. Изменения интерфейса проверьте через `python3 tests/gui_smoke.py` в графической сессии.
4. Системные команды запускаются списком аргументов без подстановки пользовательского текста в shell. Новые изменяющие операции должны иметь понятное подтверждение и объяснять возможность отмены.
5. Не включайте в коммиты личные журналы, исходные пользовательские файлы, токены, настройки аккаунтов и результаты инвентаризации своего компьютера.

Документация и интерфейс в первую очередь ориентированы на начинающих пользователей Linux.
