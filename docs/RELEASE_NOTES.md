# OpenCare — Beta 0.0.1

Первая публичная бета независимого open-source инструмента обслуживания Linux.

- Значки и названия приложений вместо списка системных библиотек.
- Интерфейс на русском с пошаговыми подсказками.
- Очистка с возможностью возврата, управление запуском программ и поддерживаемыми настройками рабочего стола.
- Дополнительные инструменты для файлов конфигураций, сравнения изменений и анализа диска.
- Лицензия MIT, без подписки и телеметрии.

## Установка

Скачайте ZIP, распакуйте его, откройте терминал в папке `opencare` и выполните `sh run.sh`.
Нужны Linux, Python 3.10+, Tk 8.6 и графическая сессия. На Mint/Ubuntu/Debian Tk можно установить командой `sudo apt install python3-tk`. Сам OpenCare запускается без sudo.

Это бета: сначала используйте проверку без изменений. Копии для отмены занимают место до их отдельного окончательного удаления. Удаление приложений выполняет штатный менеджер пакетов и не отменяется журналом OpenCare. Поддержка настроек пока ограничена Cinnamon/Nemo и GNOME. Все ограничения — в README.
