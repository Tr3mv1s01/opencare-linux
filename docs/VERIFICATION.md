# Проверка Beta 0.0.1

## Автоматические проверки

- 26 модульных сценариев: сканирование, возраст файлов, карантин/восстановление, конфликты, ссылки и выход за пределы домашней папки, автозагрузка, сравнение состояния, одинаковые файлы, приватные данные, команды удаления, ошибки dconf, выбор настроек по рабочему столу и инвентаризация приложений.
- GUI-сценарий с временной домашней папкой: меню для новичка, помощь, проверка без изменений и переход к файлам, перенос → возврат, отмена автозагрузки и редактор.
- Проверка синтаксиса модулей.
- Проверка сборки и контрольных сумм ZIP.

## Локальная интеграция

Проводились проверки в Linux Mint 22.3 / Cinnamon / X11, Python 3.12 и Tk 8.6:

- Загрузка реального меню приложений, системных значков и подтверждённых связей с пакетами.
- Отсутствие подстановки списка библиотек вместо списка приложений.
- Чтение автозагрузки, конфигураций и сканирование кэша без удаления.
- Временное переключение семи поддерживаемых параметров Cinnamon/Nemo с чтением записанного значения и точным возвратом исходного состояния, включая пользовательские переопределения.

Личные пути, результаты инвентаризации конкретного компьютера и содержимое пользовательских файлов в репозиторий не включаются.

Удаление настоящих приложений и очистка настоящих пользовательских данных в рамках проверки не выполнялись. Визуальный эффект каждого параметра рабочего стола отдельно не подтверждался. Эти проверки не доказывают совместимость со всеми дистрибутивами.
